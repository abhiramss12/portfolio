## ▶️ Run Locally

Open the project folder in VS Code.

Install the **Live Server** extension.

Right-click on `index.html`

Select

```
Open with Live Server
```

---

## 🌍 Deploy to GitHub Pages

### 1. Create Repository

Example

```
portfolio
```

### 2. Push Project

```bash
git init

git add .

git commit -m "Initial Portfolio"

git branch -M main

git remote add origin https://github.com/abhiramss12/portfolio.git

git push -u origin main
```

---

### 3. Enable GitHub Pages

Go to

```
Settings
```

↓

```
Pages
```

↓

```
Deploy from Branch
```

↓

```
main
```

↓

```
/root
```

↓

Save

After 1–2 minutes your portfolio will be live.

Example

```
https://abhiramss12.github.io/portfolio/
```
